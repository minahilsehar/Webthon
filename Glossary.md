# Glossary

| Term | Meaning |
|---|---|
| Administrator | A user responsible for account, role, permission, and platform management. |
| Examiner | A user who authors examinations, manages candidates, monitors attempts, grades, and publishes results. |
| Candidate | A user assigned to take an examination and view their own published results. |
| Examination | A scheduled assessment containing instructions, questions, timing, and marking rules. |
| Question bank | A reusable collection of questions available for examiners to assign. |
| Attempt | One candidate's authorized sitting of an examination, including its assigned question snapshot and responses. |
| Autosave | Persisting a candidate's answer during an active attempt without waiting for final submission. |
| Publication | The examiner-controlled point at which graded results become visible to candidates. |
| Server-authoritative time | Scheduling and deadlines calculated by the server rather than trusting a candidate's device clock. |
| Idempotent submission | Handling repeated submission requests without creating duplicate or inconsistent results. |
| Sandbox attempt | A preview run kept separate from real candidate records, scoring, and analytics. |
